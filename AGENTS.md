# Agent Guidelines

Before building or changing UI, read `DESIGN.md`.

## Core Philosophy
- Maintain strict zero-border and zero-shadow discipline.
- Containers and cards use `#FDFDFD`.
- Secondary buttons and nested surfaces use `#F5F5F5`.
- Primary text uses `#181818` (never `#000000`).
- Every button has tactile depression `active:scale-[0.96]`.
- No `transition: all`.
